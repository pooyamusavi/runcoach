Project · LLM engineering · Sport tech

RunCoach

An AI running coach that turns free-text training notes and Garmin exports into structured data, and answers training questions with a Claude agent that calls analytics tools over real data.

View the code See the evals

What it shows

Structured extraction

Forced tool calls with a Pydantic schema; invalid model output is rejected, never stored.

Tool-using agent

A bounded loop over analytics tools, with every answer citing the tools it used.

Evals, not vibes

A labelled set scored field by field against a regex baseline.

Production habits

FastAPI, PostgreSQL, idempotent upserts, Docker, mypy strict, CI.

Example (Claude extractor, illustrative)

$ runcoach extract "Long run 28 km at 5:40/km, HR 146. Felt good until km 24, then calf tightness."
{
  "workout_type": "long",
  "distance_km": 28.0,
  "avg_pace_min_per_km": 5.67,
  "avg_hr": 146,
  "feeling": "good",
  "symptoms": ["calf tightness"],
  "summary": "Long run of 28 km at 5:40/km; calf tightness appeared after km 24."
}
